# 🎙️ Multi-Speaker Call Processor

Production-ready Python pipeline for multi-speaker call processing with **speaker identification** and **transcription**.

**Pipeline**: Diarization (pyannote) → Speaker ID (SpeechBrain ECAPA-TDNN) → Transcription (Whisper Large v3)

---

## ⚡ Features

- **Speaker Diarization** — detect who spoke when using pyannote.audio 3.1
- **Voice Identification** — match speakers to enrolled agent voices using ECAPA-TDNN embeddings
- **Transcription** — high-quality speech-to-text using Whisper Large v3
- **4GB VRAM Optimized** — sequential model loading, int8 quantization, one model at a time
- **Structured Output** — JSON results + clean human-readable transcript
- **Confidence Scores** — cosine similarity scores for each speaker match
- **Noise Handling** — skips segments < 1 second, merges consecutive same-speaker segments

## 🚀 Setup

### 1. Prerequisites

- **Python 3.10+**
- **CUDA GPU** (RTX 3050+ recommended) or CPU (slower)
- **ffmpeg** installed (for audio format conversion)

```bash
# Windows — install ffmpeg via chocolatey or download from ffmpeg.org
choco install ffmpeg

# Or download from: https://ffmpeg.org/download.html
# Add to PATH
```

### 2. Install Dependencies

```bash
cd call_processor
pip install -r requirements.txt
```

### 3. HuggingFace Token

pyannote.audio requires a HuggingFace token with access to gated models.

1. Create account at [huggingface.co](https://huggingface.co)
2. Accept terms for:
   - [pyannote/speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1)
   - [pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0)
3. Create token at [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
4. Set environment variable:

```bash
# Windows PowerShell
$env:HF_TOKEN = "hf_your_token_here"

# Linux/Mac
export HF_TOKEN="hf_your_token_here"
```

## 🎯 Usage

### Step 1: Enroll Agent Voices

Place clear audio samples (3-10 files, 5-30 seconds each) in agent directories:

```
data/agent_samples/
├── agent_abhishek/
│   ├── call_sample_1.wav
│   ├── call_sample_2.wav
│   └── meeting_clip.wav
├── agent_rahul/
│   ├── intro.wav
│   └── sample.wav
```

Then run enrollment:

```bash
python enroll_agents.py
```

This creates `embeddings/agent_embeddings.pkl` with voice fingerprints.

### Step 2: Process a Call

```bash
python main.py --input path/to/call_recording.wav
```

### Advanced Options

```bash
# Use CPU instead of GPU
python main.py --input call.wav --device cpu

# Different Whisper model (faster but less accurate)
python main.py --input call.wav --whisper-model base

# Adjust speaker matching sensitivity
python main.py --input call.wav --threshold 0.3

# Hindi/other language transcription
python main.py --input call.wav --language hi

# Full options
python main.py --help
```

## ⚙️ Performance Notes (RTX 3050 — 4GB VRAM)

| Stage | Model | VRAM Usage | Strategy |
|-------|-------|------------|----------|
| Diarization | pyannote 3.1 | ~1.5 GB | Load → process → unload |
| Speaker ID | ECAPA-TDNN | ~0.5 GB | Load → process → unload |
| Transcription | Whisper Large v3 | ~3.5 GB | int8 quantization via CTranslate2 |

**Key optimization**: Models are loaded sequentially — only one is in VRAM at a time.

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| `OutOfMemoryError` | Use `--whisper-model medium` or `--device cpu` |
| `pyannote access denied` | Accept model terms on HuggingFace + set HF_TOKEN |
| `soundfile` errors | Install ffmpeg and ensure audio is not corrupted |
| Low speaker match accuracy | Add more diverse voice samples, lower threshold |
| Wrong language | Set `--language` flag (e.g., `hi` for Hindi) |

---

## 📝 Tips for Best Results

- **Agent samples**: Use 5-10 clear recordings per agent (different phrases, no background noise)
- **Call quality**: 16kHz+ sample rate, mono preferred
- **Threshold tuning**: Start at 0.25, increase if too many false "Customer" labels, decrease if wrong agent names
- **Language**: Set `--language` explicitly for non-English calls
