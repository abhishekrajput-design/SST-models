================================================================================
✅ WHAT THE RESTART SCRIPT DOES
================================================================================

  1. Pulls latest code from GitHub (git pull origin main)
  2. Stops existing server on port 8080
  3. Clears old logs
  4. Starts new server with unbuffered output
  5. Waits 3 seconds for startup
  6. Checks status with /api/status
  7. Shows server URL

📊 SCRIPT CONTENT
================================================================================

The restart.sh script is located at: /path/to/SST-models/restart.sh

Key operations:
  1. cd "$REPO_DIR" && git pull origin main
  2. sudo fuser -k 8080/tcp
  3. : > "$LOG"  (clear log)
